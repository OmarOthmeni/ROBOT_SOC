# BoB Robot — Nios II System-on-Chip on a Cyclone V FPGA

Course project (ENSEEIHT, Electrical Engineering, 1st year "BE Robot"). A mobile robot controller
built as a system-on-chip on a **Terasic DE1-SoC** board (**Intel Cyclone V, 5CSEMA5F31C6**): a
32-bit **Nios II** soft processor on an Avalon-MM bus, custom **VHDL** peripherals, a hand-built
address decoder, and C firmware that drives them through memory-mapped registers.

## What the system does

| Function | Hardware (VHDL / schematic) | Firmware (C) |
|---|---|---|
| **Motor drive** | `vhdl/moteurs.vhd`: PWM generation, speed and direction per motor | writes duty cycle and direction registers |
| **Obstacle sensing** | `vhdl/trigger.vhd`, `vhdl/echo.vhd`, `vhdl/capteurs_robot.vhd`: drive 3 SRF05 ultrasonic sensors (left, centre, right) and measure echo width | programs trigger period, duty cycle and echo limit, reads distances |
| **Manual control** | `vhdl/commandes_manuelles.vhd`: joystick and switches | decodes 8 joystick directions + stop button |
| **Display** | `vhdl/afficheurs.vhd`, `vhdl/LED.vhd`: seven-segment displays and LEDs | shows the current command / state |
| **Bus interface** | `hardware/DECODAGE_ROBOT.bdf`: address decoder generating chip selects CS0–CS7; `vhdl/Data_Multiplexeur.vhd`: read-data mux | `logiciel/ROBOT_EEEA_1A/robot_def.h` maps every register to a C pointer |
| **Clocking / reset** | `mapll.tdf` (PLL), `vhdl/downclock.vhd`, `vhdl/reset_gen.vhd` | — |

### Address map (chip-select zones)

| Zone | Peripheral |
|---|---|
| CS0 | Seven-segment displays |
| CS1 | Status LEDs |
| CS2 | Robot sensors (ultrasonic distance) |
| CS3 | Switches / joystick |
| CS4 | Motor drive (direction and duty cycle) |


## Build

Tools: Quartus Prime 18.1 with Platform Designer and the Nios II Software Build Tools.

1. Open `peripheriques.qpf` in Quartus. In Platform Designer, open `system/NIOS_ROBOT_LAST.qsys`
   and click **Generate HDL**.
2. Compile the Quartus project and program the `.sof` onto the DE1-SoC.
3. Regenerate the BSP and build the firmware (Nios II Command Shell):
   ```bash
   cd logiciel/ROBOT_EEEA_1A_bsp && ./create-this-bsp
   cd ../ROBOT_EEEA_1A && make
   nios2-download -g ROBOT_EEEA_1A.elf
   ```

Generated files (Platform Designer HDL, BSP sources, object files, Quartus databases) are not
tracked; see `.gitignore`.
